# テスト項目

テストで確かめる中身の置き場です。本体のプロンプトも点検役（test-reviewer）も、このファイルを読みます。項目を変えるのは、えだが決めたときだけです。

- 各項目の中身は `docs/external-design.md` の番号で指します（B-nn＝振る舞い、R-nn＝読み上げる文、AT-nn＝受け入れテスト、P-nn＝参考の不具合）。表の「入力の例」と「読み上げる文」が、そのままテストの入力と期待値です。
- 「自動」は `cargo test -p edaberu_core` で回るテスト。「VCで聞く」はテスト用のサーバーで耳と画面で確かめるテスト。「実測」はVPSで数字を取ること。
- 自動テストの書き方（点検役はここを見て「弱い」を判定する）
  - 期待値は、表の文字列を手で写す。実装の関数で期待値を作らない
  - 境界を必ず入れる（ちょうど30文字と31文字、空、書記素が1文字に見える物、URLの末尾の記号、0件と上限ちょうどと上限＋1）
  - 外の物（Discord・VOICEVOX・時計）は偽物か注入で置き換える。10秒などの待ち時間は短い値を注入して、実際には待たない
  - 点検の指摘は、実装を1か所わざと壊してテストが落ちることで確かめる（落ちなければ、そのテストは弱い）

## 実測（1周目・VPS）

① `cargo build --release -j 1` がVPS（Ubuntu 22.04・メモリ1.9GiB＋スワップ2GiB）で通る。かかった時間・メモリの最大・スワップの最大を記録する（4節の1番）
② VOICEVOX ENGINE（Docker・127.0.0.1:50021）がVPSで動き、30文字の文の合成が返る。1回あたりの秒（10回の最大と中央値）と、コンテナのメモリの最大を記録する（4節の2番）

## edaberu_core（3周目・自動）

③ `config`：ファイルが無い／書き方が壊れている／知らない項目がある／必須の項目が無い／`max_chars = 0`／トークンが無い、のそれぞれで、終了の理由が返る。ファイルが無いときは見本をコピーする手順が含まれる（AT-26。B-38〜B-42・B-44）。`config.example.toml` がそのまま読める
④ `names`：R-36・R-41・R-42 の各行（AT-34 の名前の部分）。絵文字の判定は「Unicodeの絵文字の一覧に載る物」だけを消し、♪☆★① は残す（R-15・R-16）
⑤ `speech` 置き換えと読まない物：R-01〜R-21 の各行の「入力の例」→「読み上げる文」（AT-31）
⑥ `speech` 添付・スタンプ・投票：R-22〜R-26 の各行（AT-32）
⑦ `speech` 長文と区切り：R-27〜R-35 の各行と B-29（AT-33）。`max_chars = 10` でも1つ通す
⑧ `speech` 名前の省略と入退室の文：R-37〜R-40 と R-43（AT-34・AT-35）。「直前の人」はIDで比べる。入退室の文には `name_mode` と文字数の制限が当たらない
⑨ `intake`：B-21〜B-26・B-48 の各条件で「読む／入り終えたら読む／読まない」が番号どおりに返る（AT-17）。「！すごい」は読む、「!play」は読まない
⑩ `voice_rules`＋`state`：B-01〜B-18 の各条件の出来事を渡すと、「botの動き」どおりの指示の並びが返る（AT-02）。B-15〜B-17 で、入り直しは1回だけ・2回目の失敗のあとは入り直さない・Discordへ書く指示は出ない（AT-12）。人と他のbotを分けて数える。自動参加の停止は、対象のVCが空になると消える
⑪ `queue`：まだ読んでいない件をIDで外せ、読み上げ中の件は最後まで読まれ、編集の知らせでは何も変わらない（AT-19）。21件目を入れると1件目が捨てられ、捨てたことがログに出る（AT-20）。区切りが3つある発言は順に声が作られ順に流され、間に無音は足されない（AT-21）。読む仕組みが止まったら作り直される（B-47）
⑫ `tts`（`Voicevox`）：返事をしない偽のVOICEVOXに対して、打ち切りの時間であきらめ、やり直さず、その発言の残りを飛ばして次へ進み、待っている間もほかの処理が止まらない（AT-22。B-32・P-5）。正常な偽のサーバーには `/audio_query` → `/synthesis` の順で呼び、wavのバイト列が返る。`/speakers` から話者の名前が取れる（B-34）

## edaberu（2周目・4周目・VCで聞く）

⑬ AT-01 の形：人が対象のVCに入ると、botがスピーカーミュートで入ってきて、音が鳴る（4節の3番・16番。2周目は固定のwav、4周目は「{名前}さんが参加しました」の声）
⑭ AT-37 の形：メモリ上のwavを渡して鳴る。一時フォルダにwavが残らない（4節の4番・P-6）
⑮ AT-08・AT-09・AT-10・AT-29 の形：botが「切断された」「別のVCへ移された」「ネットの不調で切れた」を区別できる（4節の5番。B-12・B-14・B-15 が分かれる）。切断されたまま再起動すると、対象のVCにすぐ入る（AT-09）
⑯ AT-07 の前提に「他のbotも対象のVCにいる」を足した形：起動時に、対象のVCの人（botでないユーザー）を数えられる（4節の20番）
⑰ 残りの「VCで聞く」受け入れテスト：AT-03〜AT-07・AT-11・AT-13・AT-15・AT-18・AT-23・AT-27・AT-28・AT-36（AT-14・AT-16・AT-24・AT-25 は4周目の項目の完了条件として通す）
